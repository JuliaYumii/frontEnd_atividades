Técnicas para coleta de requisitos

Uma matriz de rastreabilidade de resquisitos é uma ferramenta utilizada em gerenciamento de projetos e desenvolvimento de software para assegurar que todos os requisitos de um projeto sejam atendidos ao longo do ciclo de vida do produto.

documento

O documento de requisitos é um registro abrangente dos requisitos do projeto.

Ele pode conter:

  • Introdução
  • Requisitos funcionais
  • Requisitos não funcionais
  • Restrições
  • Assunções
  • Casos de uso
  • Aprovação
